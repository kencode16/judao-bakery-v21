# 菊島連連烘 v2.1

舒壓的麵包甜點連連看，iPhone 和電腦的瀏覽器都能玩。開場可以選難度：「易」和「中」。

**👉 開始玩：https://kencode16.github.io/judao-bakery-v21/**

（iPhone 用 Safari 打開，按「分享 → 加入主畫面」，就能像 App 一樣全螢幕玩，也能離線玩。）

## 玩法

- 點兩個一樣的甜點，能用**最多轉兩個彎**的奶油擠花線連起來，就會被吃掉。
- **易・輕鬆模式**：不計時、沒有失敗；卡住時會自動幫你重新擺盤。
- **中・挑戰模式**：
  - 每關限時，時間到要重來。
  - **同一種甜點有 3 種底色，底色也一樣才能配**。
  - **配錯扣 5 秒**；想換選擇，先點一下原本選的取消。
  - 甜點會往下（或往左右、往中間）補位，障礙物也更早出現。剩越多時間星星越多。
- 兩種難度的關卡進度和圖鑑分開收集。
- 5 個地區 × 10 關：法國、台灣、義大利與南歐、英國與美國、日本。每過一關收集一種甜點，共 55 種，圖鑑裡有每一種的口感、搭配飲品和小故事。
- 「菊島」是澎湖的別名，澎湖的縣花是天人菊。

- 甜點、飲品、道具插畫和開場的杜賓小編動畫全部用程式（Canvas）繪製，沒有使用 AI 生圖或外部圖片。
